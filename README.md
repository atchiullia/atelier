# Atelier

A production-style fashion e-commerce platform and Kubernetes platform-engineering portfolio project.

Every garment in the catalog carries structured metadata, Paris Fashion Week trends are extracted into the same schema, and a matching service curates a "Trending now, from our collection" page. Underneath it runs on a two-region setup (a Raspberry Pi edge and Azure AKS) with GitOps, eBPF networking, SLOs and a Black Friday simulation.

The whole design lives in [SPEC.md](SPEC.md). Decisions are recorded in [docs/adr](docs/adr).

**Status:** Phase 0 (foundation). Nothing here is production software yet.

**This repository is open to read, clone and run. Outside contributions are not accepted** (see [CONTRIBUTING.md](CONTRIBUTING.md)).
